# Deprecated Files

This folder contains files from the original Portfolio Optimization Dashboard project that are no longer actively used. The main project has evolved into a blog post about factor investing and index fund alternatives.

## Original Project
The original project was a Streamlit dashboard for portfolio optimization with factor analysis. These files are preserved for reference but are not part of the current blog post.

## Contents
- `scripts/` - Original Python analysis scripts
- `docs/` - Original documentation
- `results/` - Original analysis outputs
- `blog_drafts/` - Earlier versions of blog post (R Markdown, Jupyter notebooks)
- Root-level utility scripts (add_citations.py, dashboard.py, etc.)
